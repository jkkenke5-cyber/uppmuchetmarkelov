# Учёт личных расходов

Учебный проект (УП 02.01 «Осуществление интеграции программных модулей», ПМ.02): консольная программа для учёта личных расходов с анализом по категориям и контролем месячных лимитов.

## Возможности

- ввод расходов по пяти категориям: еда, транспорт, жильё, развлечения, здоровье;
- проверка каждой записи: известная категория, сумма от 1 до 100 000, не больше остатка на счёте;
- пересчёт остатка после каждого расхода;
- суммирование расходов по категориям;
- контроль месячных лимитов с указанием величины превышения;
- итоговый отчёт о расходах;
- два режима работы: интерактивный и автоматический (демонстрационный).

## Месячные лимиты

| Категория   | Лимит, р |
|-------------|---------:|
| еда         |   15 000 |
| транспорт   |    4 000 |
| жильё       |   20 000 |
| развлечения |    5 000 |
| здоровье    |    3 000 |

## Требования

Python 3.8 или новее. Сторонние библиотеки не нужны.

## Запуск

Интерактивный режим (расходы вводятся с клавиатуры, для выхода введите `q`):

```bash
python expenses.py
```

Автоматический режим (8 случайных расходов, воспроизводимый результат):

```bash
python expenses.py --auto 8 --seed 1
```

### Параметры

| Параметр      | Описание                                        | По умолчанию |
|---------------|-------------------------------------------------|--------------|
| `--auto N`    | сгенерировать N случайных расходов              | выключен     |
| `--seed S`    | начальное значение генератора случайных чисел   | случайное    |
| `--balance B` | начальный баланс, р                             | 50000        |
| `--name ИМЯ`  | имя пользователя в отчёте                       | Константин   |

## Структура программы

Функции `expenses.py` соответствуют блокам диаграммы IDEF0 (уровень A1):

| Блок IDEF0                           | Функции                                    |
|--------------------------------------|--------------------------------------------|
| A1 Принять запись о расходе          | `check_expense`                            |
| A2 Распределить расходы по категориям| `total_by_category`                        |
| A3 Рассчитать остаток и проверить лимиты | `find_overruns`, `limit_of`, `process_expense` |
| A4 Сформировать отчёт о расходах     | `make_report`, `format_money`              |

Режимы ввода реализованы в `auto_mode` и `interactive_mode`, разбор параметров и запуск — в `main`.
